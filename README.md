# Egypt Agriculture & Crop Yield Analysis (1990–2024)

## 📊 Project Overview

This Power BI project analyzes Egypt's agricultural production, crop yield, and harvested area from 1990 to 2024.

The dashboard explores long-term production trends, compares crop performance, and examines the relationship between production and harvested area.

## 🎯 Objectives

- Analyze agricultural production trends over time.
- Compare crop performance based on production and yield.
- Monitor total harvested area.
- Identify top-performing crops.
- Explore the relationship between production and harvested area.
- Track year-over-year changes in key agricultural metrics.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

- Total Production
- Average Yield
- Total Area Harvested
- Year-over-Year Growth
- Production Trend Over Time
- Top Performing Crops
- Production vs. Area Harvested
- Interactive Crop and Year Filters

## 💡 Key Insights

### 1. Long-Term Production Growth

Egypt's agricultural production shows a clear overall upward trend between 1990 and 2024, although production fluctuates across individual years.

### 2. Sugar Cane Leads Production

Sugar cane is the highest-producing crop among the top-performing crops displayed in the dashboard, with approximately 525.6M in production.

### 3. Production Is Not Driven by Area Alone

The comparison between production and harvested area shows that a larger harvested area does not necessarily result in the highest production.

Sugar cane achieves the highest production among the displayed top crops while having a substantially smaller harvested area than wheat.

### 4. Yield Plays an Important Role

The differences in yield between crops highlight the importance of productivity, not only the amount of land harvested, when evaluating crop performance.

### 5. Crop Performance Varies Significantly

The dashboard shows considerable differences between crops in production, yield, and harvested area, making crop-level comparison important for understanding agricultural performance.
